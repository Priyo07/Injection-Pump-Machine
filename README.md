This project simulate the injection pump machine with linear actuator model
Component used for this project :
1. Arduino nano
2. Motor Driver
3. Stepper motor
4. Keypad
5. Limit switch / switch
6. Buzzer
7. LCD 16X2

The working principle is stepper motor placed on linear actuator and it pushes a block. The block is connected to the syringe and it can be pushed or pulled.
Keypad is used for menu selection and emergency procedure.

Limit switch is used to determine the end and start of the linear actuator mechanical aspect.
